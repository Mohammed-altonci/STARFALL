# STARFALL Android — النسخة المعدّلة

## بناء نسخة أندرويد من الهاتف

1. أنشئ مستودعاً جديداً في GitHub باسم `starfall`.
2. ارفع محتويات هذا المجلد إلى المستودع: `main.py` و`buildozer.spec` ومجلد `.github`.
3. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
4. بعد نجاح البناء، نزّل ملف `starfall-apk` من قسم Artifacts.

## ما الذي تغيّر؟

- بعد خسارة اللاعب يظهر خيار اختياري لمشاهدة إعلان مكافأة للحصول على محاولة واحدة إضافية في نفس المرحلة.
- بعد إنهاء المرحلة أو الفوز النهائي يظهر خيار اختياري لمشاهدة إعلان مكافأة لمضاعفة العملات التي كسبها اللاعب في تلك الجولة.
- كل مكافأة تُمنح مرة واحدة فقط، وبعد تأكيد اكتمال الإعلان بالكامل من جسر الإعلانات.
- إذا لم يكتمل الإعلان أو لم يكن جسر الإعلانات موجوداً، فلا تُمنح المكافأة.
- أضيفت أزرار لمس وفأرة، مع اختصارات لوحة المفاتيح: `A` لطلب إعلان المتابعة بعد الخسارة، و`D` لطلب إعلان مضاعفة العملات.

## تنبيه مهم بخصوص AdMob

هذه النسخة تحتوي على واجهة الخيارات ونقطة الربط البرمجية، لكنها **لا تحتوي بعد على Google Mobile Ads SDK ولا على إعلان حقيقي**. لذلك ستظهر رسالة أن الإعلانات غير متصلة حالياً، ولن يحصل اللاعب على مكافأة بمجرد الضغط على الزر. هذا مقصود لمنع منح مكافآت مجانية أو الادعاء بأن إعلاناً قد شوهد.

لجعل الإعلانات حقيقية، يلزم في خطوة لاحقة إضافة جسر أندرويد أصلي يربط Google Mobile Ads SDK بواجهة `starfall_ads_native.show_rewarded_ad(placement, callback)`، ثم ضبط معرّف التطبيق ووحدات الإعلانات الاختبارية. يجب اختبار الإعلانات بمعرّفات الاختبار أولاً، وعدم استخدام إعلانات حقيقية أثناء التطوير.
